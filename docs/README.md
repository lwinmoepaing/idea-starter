# docs/

Specs, Lean Canvas PNGs, pitch summaries. Written by `business-canvas` and `pitch-summary`; hand-specs by you.

## What lands here
- `#NNNN-<slug>-canvas.png` — Lean Canvas rendered via the `tldraw` MCP (`business-canvas`)
- `#NNNN-<slug>-canvas.tldr.json` — editable shapes JSON (re-render after tweaks)
- `#NNNN-<slug>-pitch.md` — pitch-ready summary (Story / Idea / Problem / Solution / Purpose), regenerated by `pitch-summary` after every feature drop. Slide source material.
- `<idea>-spec.md` — optional hand-spec / PRD before `mvp-plan` runs

Slug + ID thread from `workflow/*/#NNNN-<slug>.md`.

## Flow
1. `validate-idea` + `pain-hunt` + `marketing-plan` fill `workflow/`
2. `business-canvas` reads all three → renders PNG here
3. Optional: hand-spec next to the PNG before `mvp-plan` decomposes phases
4. After `mvp-execute` ships the last phase for an ID, `pitch-summary` auto-writes `#NNNN-<slug>-pitch.md`
