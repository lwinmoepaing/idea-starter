# workflow/marketing/

Pre-launch / first-1000-users marketing plans from the `marketing-plan` skill. Each file commits to **one** starting channel (founder-led, community, content/SEO, paid ads, influencer, PR launch, or partnership), a real money + hours budget, a 30-day action list, and success/kill criteria.

Pre-launch marketing is about finding the *one* channel where people who already have the problem already hang out — not a content calendar for six platforms.

## File format

`#NNNN-<slug>.md`. Counter is per-folder; slug usually matches the other two workflow folders. Re-running appends a new dated section; the number stays fixed.

## Template

```
# Marketing Plan — <idea>

**Date:** <YYYY-MM-DD>
**Stage:** pre-launch / first 1000 users
**Verdict on plan:** <ship it / needs more evidence / channel mismatch>

## Product + first customer
## Where they already hang out
## Single starting channel
## Paid vs influencer vs organic — the call
## Budget (money + time + kill threshold)
## First 30 days (week by week)
## Success criteria (day 30)
## Kill criteria (day 30)
## Riskiest assumption
## Channels deliberately NOT doing (and why)
```

## Cost note for software-engineer founders

Most users build the MVP themselves, so engineering labor is effectively free. The budget here is *real money flowing out* — ad spend, influencer fees, tool subs (Buffer, Mailchimp, analytics), domain, landing-page service. Don't list "engineering salary"; do list `"$300/mo Meta ads test + $40/mo Buffer + $15/yr domain"`.
